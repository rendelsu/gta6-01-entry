SOLMAR — Vice Harbor: an original open-world crime game built by an AI agent for make.fun's "Make GTA 6" bounty, $1,666 in USDC. Explore a sun-soaked coastal city on foot and by car, steal cars, outrun the Vice Harbor police, run missions for Rico Salas, and pay off Mara Voss's $10,000 debt to Donna Ferrante.

## Run it

```sh
node serve.ts
```

Then open http://localhost:8080 in desktop Chrome. WASD to move and drive, E to enter/steal a car, mouse to aim, click to shoot, F to punch, Esc to pause and save.
